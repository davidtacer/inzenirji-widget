# inzenirji-widget

Conversational site editor for Inženirji.si client websites ("Urejevalnik s pogovorom").

The client opens `their-site.si/uredi`, writes what to change, reviews the result on a hidden test site
and publishes it with one click. See `docs/` for the product spec, architecture and current state
(start with `docs/HANDOFF.md`).
